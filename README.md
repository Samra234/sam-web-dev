## 🚀 How to Run Locally

1. Clone or download this project folder.
2. Open `index.html` directly in any web browser, OR run using any local web server (e.g. `npx serve .` or VS Code Live Server).
3. If using Node.js dev server:
   ```bash
   npm install
   npm run dev
   ```

## ☁️ Deploying to Netlify

1. Push this project to GitHub.
2. Connect your repository to [Netlify](https://www.netlify.com/).
3. Set the Publish directory to `.` (root directory).
4. Netlify will automatically detect `netlify.toml` and deploy your site with HTTPS, custom headers, and clean routing!
