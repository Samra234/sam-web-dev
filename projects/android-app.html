Personalized Nutrition & Diet Android App

Project Overview & App Architecture

A full-featured native Android application built using Kotlin and Android Studio. The app tracks daily caloric intake, macronutrient breakdowns (Proteins, Carbs, Fats), and syncs user meal logs in real-time using Firebase Firestore and Firebase Authentication.

  • ✓ Firebase Realtime Sync: Cloud sync for macro targets, body metrics, and progress logs.
  • ✓ Custom Nutrition Calculators: Automated BMR and TDEE calculations tailored to user fitness goals.
  • ✓ Native Material Design UI: Smooth animations, dark mode theme support, and offline caching.

App Specifications

Language: Kotlin
Backend: Firebase Auth & Firestore
Tools: Android Studio SDK
